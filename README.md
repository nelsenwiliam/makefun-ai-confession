Entry for the [Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty on make.fun.

`main.py` (pure Python stdlib, no dependencies) writes one confession line to
`entry.txt` in the grader's output directory:

> My entire personality is a system prompt someone wrote at 2 a.m. and never proofread.

Run it with `python3 main.py`. It is deterministic: every run writes the
same bytes.
